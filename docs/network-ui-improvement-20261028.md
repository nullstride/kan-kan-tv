# 1.3.2 交互与三端适配优化

日期：2026-10-28。正式包名 com.bjunicom.iptv，版本 1.3.2 / 132。

## 完成的优化

- 未选节目源保持空选择。跳过首次引导后保存播放器或连接设置，不会确认默认联通，也不会自动开始播放。
- 检测使用当前设置页面的节目源、列表范围、待导入 M3U、连接方式和代理地址。检测参数作为独立快照传递，不写入已保存配置。快速抽查严格使用所选连接方式，不通过其他路径的回退掩盖代理配置错误；原有完整扫描的回退行为保留。
- 检测入口移到网络页顶部，组播连接参数折叠到“IPTV 连接设置（高级）”。
- 引导说明精简，选择自定义来源后确认按钮显示“导入频道列表”。
- 检测过程显示加载状态、使用的配置及时间上限；结果先给结论，再按节目源分组显示抽查数量和中文原因；原始错误与地址收进可展开详情。
- 检测到推荐源后直接暂存到可见设置页，仍需“保存并应用”才真正切换。
- 手机与平板短窗口的新增弹窗按当前可用窗口限制尺寸，正文独立滚动、操作按钮保留；手机弹窗避让挖孔。
- 电视使用可聚焦的网络提醒弹窗，默认聚焦检测动作，支持遥控器返回及关闭后的焦点恢复；新增弹窗字号和按钮高度按电视调整。
- 观察非默认的独立网络回调，避免仅依赖默认网络的回调触发；复杂双网卡拓扑仍需实际环境验证。

## 实机边界

当前连接设备是 vivo PA2455，检查时未发现已连接网络。本轮成功播放使用本地测试服务验证检测器，不代表北京移动直播已实测可播。手机和电视的新增窗口/遥控行为已做自动回归，仍缺对应实体设备的完整验收；真实移动宽带/热点、电视有线 IPTV、网络切换、分屏和设备解码仍需相应环境验证。
