# 手机横屏交互适配

设备识别先检查电视系统类型、TELEVISION / LEANBACK 特征，再使用 smallestScreenWidthDp >= 600 区分平板与手机；横屏宽度不会把手机误判为平板。

手机使用 activity_main_phone.xml 的独立结构。业务控制器、频道仓库、设置草稿与播放器继续共用。平板和电视沿用原布局与对应输入行为。

## 与已确认 HTML 的对应

- 播放页：左上频道，右上收藏与更多，底部单行频道信息和上一台 / 台号 / 下一台。
- 频道：292dp 抽屉、单行频道、搜索和可用筛选；宽屏保留右侧 HUD，窄窗口把抽屉抬到播放条上方。
- 更多：右上锚定滚动浮层，包含设置、节目源、M3U、数字选台、比例、重连、信息与扫描。
- 设置：整页、顶部保存取消、左侧分类、右侧滚动内容。取消丢弃草稿，保存并应用才提交。
- M3U：整页内容 / 检测结果标签；伸展编辑器与固定检测、合并暂存、暂存动作。继续使用 CustomM3uDialogHelper 的校验和草稿逻辑。
- 数字盘：左侧预览与立即播放，右侧 3×4 数字、清空与退格。
- 扫描：参数 / 结果标签、多列参数、固定开始停止和结果入口；较窄窗口使用两列并允许滚动。

## 共享 UI

播放玻璃仍由 VideoGlass / GlassLens 绘制，手机独立按钮使用各自包装面板接入同一次视频捕获。没有复制 HTML 中的旧玻璃配色、修改 AGSL 或新增独立材质实现。设置和按键复用共享主题、drawable 与 GlassMotion；后续共享材质更新会继续作用到手机。
