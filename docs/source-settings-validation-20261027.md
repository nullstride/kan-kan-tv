## 数据与交互

- 节目源选择及 M3U 检测均先保存在本次设置草稿中。只有“保存并应用”才提交；取消、返回、文件选择取消、检测失败均不切换当前源。
- 导入支持本地文件、粘贴内容、设备/U 盘文件查找、内容检测与可选连通性检测。合并导入生成独立的自定义列表，可随时切回原内置源。
- 节目源预览读取指定来源，不修改设置或正在播放的频道；显示的是加载数量，不承诺直播可播放数量。
- 从有修改的设置跳转扫描器时，可保存并继续、放弃并继续或留在设置。保存动作包含网络、内核与节目源全部草稿。
- 保存新列表后保留仍存在的当前频道，否则播放第一项；一次保存只安排一次播放重载，未修改时不重启播放器。
- 自定义内容使用 AtomicFile 持久化；写入失败不修改生效中的节目源，设置保持打开以便重试。
- 扫描结果支持“应用为节目源”“仅导出”“返回结果”。零成功频道时禁用应用，避免空结果或全部失败时将原列表误认作新扫描结果。
- 设置与扫描页复用 PlaylistExporter 导出 M3U 和 CSV。写入独立 exports 目录，不覆盖作为生效列表使用的 modified_iptv*.m3u；可通过系统分享面板取出文件。
- 精选/历史频道开关只在实际支持两套数据的内置源下可用，自定义源、电信完整源以及已保存列表给出说明。
