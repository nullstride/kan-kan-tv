# 仓库隐私保护

提交和推送会检查暂存内容、提交说明、公开身份及全部可达历史。维护者默认使用公开别名；贡献者使用自己的 GitHub noreply 身份。诊断只输出文件、行号和规则，不回显命中值。

首次克隆运行 tools\aio.cmd privacy-install 安装钩子；贡献者可随后配置自己的公开别名和 noreply 邮箱。CI 独立复查历史。禁止跳过钩子或关闭检查来规避问题。

文档使用相对路径、环境变量和设备占位符。密钥、签名文件、个人路径、序列号、MAC、私人截图、备份、交付物和原始日志不得提交。

内置节目源不能包含账号或鉴权参数，已有上游指纹豁免已移除。用户在设备中导入的自有列表不属于仓库内容，不应复制到公开问题或测试样本。

第三方开源版权声明必须保留。已审查的官方许可文本按精确 Git blob 指纹放行其原有公开联系信息；少量源码版权联系行按路径及整行原文放行，不能放行同文件新增的其他邮箱。完整来源见 THIRD_PARTY_NOTICES.md。

本机可以在 Git 内部目录保存 privacy-local.json，增加额外禁止出现的本机身份标记；实际值不属于版本控制。历史误提交不能仅通过新增删除提交清除，应先保持私有并评估平台留存及其他副本。

第三方源码归档按已核验的文件路径和 SHA-256 精确匹配，保留上游公开署名。改动归档或新增压缩包会阻止提交，需先审查来源再更新指纹。
