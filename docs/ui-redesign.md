# 看看电视 · 原生界面升级

本次沿用原生 Android Java、现有播放器和频道库。只调整视觉、交互呈现及品牌资源。

## 功能保留清单

| 功能 | 新界面入口 |
| --- | --- |
| 频道分类、搜索名称/台号/地址、仅看可用 | 左上角「频道」侧栏 |
| 收藏、取消收藏、收藏分类 | 播放控制栏「收藏」、长按频道、原遥控器快捷键 |
| 上下换台、数字选台、台号预览 | 底部控制栏、侧栏数字入口、原手势及遥控器按键 |
| 画面比例、重新连接 | 底部控制栏及快捷菜单 |
| 流地址、轨道、解码器、分辨率、速率、帧率 | 右上角「信息」，支持选中文字 |

| 记忆上次频道、断流恢复、本地代理回退 | 原播放流程保留 |

## 行为变化

- 频道侧栏打开时隐藏播放控制；浏览、搜索不再被六秒计时器打断。收起后恢复控制和计时。
- 失败状态保留重连、设置、扫描入口；未知帧率不再显示虚构的 25 fps。
- 浅色表示焦点，当前频道另用文字与底色标记。触屏及遥控器均保留。
- 主画面不常驻技术地址，完整信息移到「信息」弹窗。未添加虚构节目单或 EPG。
- 设置改为单层面板：左侧「网络连接 / 播放设置 / 频道管理」分类，右侧独立滚动，底部固定「取消 / 保存并应用」，移除反复嵌套的分组卡片。
- udpxy 地址仅在路由器代理模式显示；解码和 OpenSL ES 选项仅在 IjkMediaPlayer 内核可操作。跨分类保留编辑草稿，取消不保存。
- 遥控器在分类栏上下移动即可切换，右键进入设置项，设置行左键返回分类；触屏点击同步分类及焦点状态。

## 材质实现及限制

`VideoGlass` 独立于播放器，通过 PixelCopy（SurfaceView，Android 7+）或 TextureView 截取视频低分辨率画面，在工作线程做模糊，按视频实际位置绘制到面板后方。最大采样 160×160，每 900ms 一次，只在面板可见且 Activity 活跃时执行。切台清空旧画面，销毁时释放线程。

无有效视频表面、截图不支持或 Android 7 以下的 SurfaceView 使用半透明渐变与高光边框。它是 Android 上的玻璃风格实现，不是 Apple 的系统 Liquid Glass 或实时光学折射。
