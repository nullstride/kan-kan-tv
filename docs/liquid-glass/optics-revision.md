# 2026-10-27 材质纠正

用户反馈：实机效果明显弱于参考开源项目。

根因：上一版+5dp折射与上游默认-70dp方向相反且幅度弱；全局0.40亮度硬上限丢失亮部细节；低分辨率采样和五点偏移不是真正连续模糊；面板上再次叠加暗色渐变。

本轮：保留30Hz同步采样与32ms过渡；单独保存原始MIT shader供debug同场景参考；恢复负向折射并按控件尺寸定厚度；shader内轮廓高光与暗部厚度；去掉全局亮度硬截断和叠加压灰；静态背景提升采样清晰度；用文字阴影和适度局部背衬验证可读性。

先在同一平板、同一照片/棋盘格上对照上游shader和实际控制条，再复测Surface/Texture动态片及隐藏态。原有频道、设置、播放、网络、收藏、扫描逻辑保持本轮只读。验证不得用截图代替视频稳定性。

## 后续收敛：背景明暗与前景可读性

本节为已撤回的尝试记录。用户反馈逐段文字随背景变色会使密集列表杂乱，故已移除亮度采样、前景变色与定时扫描；当前策略见 [readability.md](readability.md)。

- 新增 GlassForeground：在各段文字实际占用区域采样背景，同时合成按钮、搜索框、焦点行的背景，选择深色或原有浅色文字；搜索提示与已有 tint 的按钮图标同步调整。
- 保留焦点、选中、按下、禁用和强调色，兼容列表复用后重新绑定配色。120ms 检查一次，使用明暗滞回和 240ms 稳定时间减少动态画面的频繁跳色；回退材质恢复原配色。
- 玻璃边缘的暗肩缩窄并减弱，折射区与中间区域保持同样的轻模糊。色散只叠加偏移差值，避免模糊强度不同导致额外彩边。
- 新增 `tools/glass-device-check.js <serial> <output-directory>`，保存白底、黑底、照片、棋盘、回退、SurfaceView、TextureView、隐藏面板的独立证据。

验证：21 项 JVM 测试通过。Windows 当前 Robolectric 缺少 native 图形 DLL，图像合成与采样行为使用 vivo PA2455（<device-serial>）真机验证。两种视频渲染分别录制约 15 秒，均无 AGSL 初始化/绘制错误或应用崩溃；录制同时的 GPU p95 分别为 3ms、4ms。该测试是本地确定性视频，不代表运营商直播网络和所有 Android 设备。
