# 光学玻璃预览（2026-10-27）

本轮以保留折射、高光和节目原色为优先，在 Android AGSL 上近似 Apple Liquid Glass 的材质分工；不是苹果系统渲染器的移植，也不声称像素一致。

- 控制条：清除固定深色/蓝灰色染色，保持原折射、色散、光照动效，保留 0.75dp 的轻微采样散射。
- 频道侧栏：边缘仍使用 0.75dp 采样，内层平滑过渡到 5dp 的九点散射。只对亮度超过 0.4 的部分使用柔和亮部压缩，RGB 按同一增益缩放，避免额外偏蓝灰的固定色层。暗部保持原样，外缘不压缩。
- 普通频道行透明、去掉重复边框；当前播放保留轻薄提示，焦点仍白底深色字。播放控制面板略减留白。
- 普通文字、提示和图标维持固定浅色。没有恢复逐段背景采样或黑白切换。纯白背景下的 Clear 控制条仍存在对比度限制，本轮不通过整块染色遮盖它。
- API 33 以下和 AGSL 不可用时继续使用现有降级材质；本轮没有把降级效果标为 Liquid Glass。

官方依据：

- https://developer.apple.com/design/human-interface-guidelines/materials ：Regular 用于侧栏和文字较多的组件，Clear 用于媒体背景；亮背景可以另加 dimming，暗背景不必叠加。
- https://developer.apple.com/videos/play/wwdc2025/219/ ：透镜折射、几何光照与交互动效共同构成玻璃感，避免玻璃嵌套；大侧栏避免明暗翻转。

验证：项目原有构建与 90 项单元测试通过；真机结果见本次交付目录的 device-check.log 与 fixtures/。材质质量仍需用户在实际节目上评估。
