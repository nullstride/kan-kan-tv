# 看看电视 · 液态玻璃升级文档

当前材质预览（2026-10-27）：清除额外固定深色染色，播放控制保持通透，侧栏使用少量散射与亮部压缩，普通频道行去掉重复边框。实现与限制见[光学玻璃预览](optical-preview.md)；下方可读性修订中的 0.56/0.60 深色衬底已被本轮替代。

当前文字策略（2026-10-27）：普通文字、提示与图标保持固定浅色，只由白色控件的焦点/选中状态使用深色字；视频背景不参与前景配色。最新实现与社区依据见[可读性修订](readability.md)。下方验收状态是早期阶段记录。

版本：1.1；日期：2026-10-26；状态：原生 AGSL 预览已实现并安装；视频闪烁已做第一轮修复，完整验收待完成。

用户约束：升级 UI、交互、Logo，现有功能不得减少。采用原生 Android 路线，优先评估 QmDeve/AndroidLiquidGlassView，以 Kyant Backdrop 的材质层次和交互示例为参考。

本目录记录本轮折射玻璃升级。[原生界面升级记录](../ui-redesign.md)描述前一轮毛玻璃版本；[示意背景来源](../preview-image.md)仍然有效。开发方案与验证方案保留开发前目标；实际偏差和结果见实现记录与验证记录。

实施顺序：基线与依赖核验 → 单个控制胶囊验证 → 视频背景桥接 → 焦点和侧栏 → 完整回归与交付。每阶段依据验证结果推进，失败则修复或启用既定降级路径。

“构建通过”“图片背景好看”“真实视频可用”“电视兼容”是不同结论。当前18项自动化通过，vivo平板照片和独立视频夹具有证据；真实IPTV、旧系统、TV及完整性能预算尚未验收。
