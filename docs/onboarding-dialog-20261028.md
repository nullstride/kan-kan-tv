# 新手引导弹窗调整

日期：2026-10-28。

## 实现

- 新手节目源选择使用独立的 `WelcomeDialogUi` 和 `dialog_source_welcome.xml`。
- 弹窗按完整窗口居中，摄像头安全区采用对称边距，修复手机横屏时向右偏移。
- 四个选项按两行两列展示；底部检测、稍后设置、确认固定显示。大字体或更小窗口保留选项区滚动能力。
- 复用 `VideoGlass` 的同一次背景采样、AGSL regular 玻璃和旧系统降级路径；通过动态注册和移除面板管理弹窗材质，不新增捕获线程。
- 选项沿用设置的中性色、圆角和单色选中状态。只有明确确认后才保存节目源或打开导入流程；仅选中不写配置。
- 保留遥控焦点、单选读屏语义和取消返回；关闭时移除玻璃面板并恢复此前焦点。
